# Сертификат для локальных тестов

`localhost.pem` и `localhost-key.pem` — публичные тестовые данные для HTTPS-сервера
на `localhost`. Сертификат действует с 2020-01-01 до 2040-01-01; ключ не является
секретом и не используется вне тестов. Не добавляйте сертификат в системное
хранилище доверия и не используйте этот ключ для рабочих сервисов.

Тесты передают сертификат через `SSL_CERT_FILE` только в своём процессе.
Проверка Windows подменяет результат перечисления сертификатов в тестовом
процессе, не меняя системное хранилище.
